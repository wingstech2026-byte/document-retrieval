JSON API

Read-only endpoints that return JSON, for scripts and other programs. No key is needed. Errors come back as {"error": "..."} with status 400 or 404.

EndpointWhat it returns
GET /api/search?q=…ranked results, total, spelling suggestion and facet counts. Parameters: q (full query syntax), type, year_from, year_to, author, all=1, sort=relevance|year, limit (max 100), offset
GET /api/doc/{id}metadata and download link; add ?text=1 for the full text
GET /api/related/{id}the most similar documents (limit)
GET /api/compare?a={id}&b={id}TF-IDF cosine, shared and distinctive terms, author and keyword overlap
GET /api/insights/{id}key terms, extractive summary, reading time
GET /api/explain/{id}?q=…BM25 breakdown of a document's score
GET /api/statscollection and index statistics
GET /doc/{id}/filethe original file, byte for byte
GET /doc/{id}/cite/bibtex (or ris, apa)a reference to download
GET /export?q=…&fmt=csv (or json)up to 1000 results as a file

Example

curl "{{ base }}/api/search?q=%22posting+list%22&type=patent"
import requests
r = requests.get("{{ base }}/api/search", params={"q": "vibration -federated year:>=2022", "limit": 5})
for hit in r.json()["results"]:
    print(hit["score"], hit["doc_id"], hit["title"])

Try it: /api/search?q=vibration&limit=3
